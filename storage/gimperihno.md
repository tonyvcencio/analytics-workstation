# Gimperihno

## Role

Secondary non-critical storage device used for testing, scratch data, and expendable workloads.

## Notes

Gimperihno is intentionally not trusted with irreplaceable data.

## Intended Uses

- Temporary datasets
- Scratch storage
- Test databases
- Cache or staging workloads
- Disposable experiments

## Not Intended For

- Primary backups
- Sole copies of important files
- Critical system data
